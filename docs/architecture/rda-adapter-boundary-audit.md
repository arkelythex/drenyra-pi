- Every `PASS` row above cites both a stable source path/symbol **and** at least one executable test name with its command (REQ-AUDIT-001/002). No verdict rests on policy wording alone.
- Source-level ownership findings cite exact paths and symbols (e.g. `lib/authority-gates.ts` → `deriveRequiredMateriality` → `deriveMateriality(request.input)` + `orderOf` floor). - Violations found: **none** in WU1 — every guard passed against the existing green kernel-delegation path, so no conditional correction was applied (T-WU1-003 marked `N/A`).
